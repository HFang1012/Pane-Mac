Connect GoatCounter

Only people with Pane’s GoatCounter token can see these numbers.

  1. Open GoatCounter’s API page and scroll to Add new API Token.
  2. Name it Pane stats, tick only Read statistics, and click Add new.
  3. Copy the token from the API tokens list at the top and paste it here.

The token is kept only in this browser, so you won’t be asked again here. It never goes to GitHub or into the website’s files. Use Sign out to remove it.
