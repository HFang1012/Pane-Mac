Install Pane

Two ways in. The Terminal one is quicker.

1. One command Recommended

Downloads Pane, puts it in Applications and opens it.

curl -fsSL https://hfang1012.github.io/Pane-Mac/install.sh | sh
  1. Open Terminal. Press ⌘ Space, type Terminal, press Return.
  2. Paste the command and press Return. Pane opens by itself when it’s done.
  3. Turn on Pane in Accessibility when it asks (see below).
Why no security prompt? macOS only checks apps that a web browser downloaded. This command downloads with curl, so macOS opens Pane straight away. Run the same command any time to update. Had Scrawl before? It replaces the old app and keeps your drawings.

2. The regular download

Works fine, but macOS asks you to confirm once.

Applications
  1. Open Pane.dmg and drag Pane into Applications. Then eject the Pane disk.
  2. Open Pane. macOS will stop it the first time with a message like this: ! “Pane” Not Opened Apple could not verify “Pane” is free of malware that may harm your Mac or compromise your privacy. DoneMove to Trash Click Done. Don’t move it to the Trash.
  3. Allow it in System Settings. Go to Apple menu›System Settings›Privacy & Security. Scroll down to Security, where it says “Pane” was blocked to protect your Mac. Click Open Anyway, confirm with your password or Touch ID, then click Open Anyway once more.
  4. That’s it. Pane opens normally from now on. Each new download asks once again, which is another reason to use the command.
Why does macOS ask? Apple asks developers to pay for a yearly account to “notarize” apps. Pane is a free project and isn’t notarized, so macOS can’t vouch for it and asks you instead. The code is open for anyone to read on GitHub.

Then: allow Accessibility

Scrawl and Spin need this to notice when you hold their keys, and Jot to notice a double-tap. Away works without it.

  1. Go to System Settings›Privacy & Security›Accessibility and turn on Pane.
  2. Already on but Scrawl doesn’t react? Remove Pane with the – button and add it again. macOS treats each new version as a new app.
